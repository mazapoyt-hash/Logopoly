# Logopoly Chat

Онлайн-чат поддержки для сайтов — открытый клон ядра [Talk-Me](https://talk-me.ru).
Встраиваемый виджет для посетителей + панель оператора с общением в реальном
времени.

## Возможности (текущий MVP)

**Виджет на сайте (сторона посетителя)**
- Плавающая кнопка и окно чата с индивидуальным дизайном, настраивается через `data-*` атрибуты.
- Обмен сообщениями в реальном времени (Socket.IO).
- Индикатор «оператор на связи / офлайн».
- Pre-chat форма (имя, email), сохранение диалога между визитами (localStorage).
- Оценка диалога звёздами после завершения.

**Панель оператора (сторона поддержки)**
- Инбокс всех открытых диалогов с непрочитанными, последним сообщением и временем.
- Переписка в реальном времени, история диалога.
- **Живой предпросмотр — оператор видит текст посетителя ещё до отправки** (фирменная фича Talk-Me).
- Карточка посетителя: страница, источник трафика/UTM, поисковый запрос, браузер, ОС, устройство, гео (по IP), IP, первый визит.
- Редактирование контактов, категория, заметки оператора, блокировка посетителя.
- Шаблоны быстрых ответов (общие и личные).
- Статусы оператора (в сети / отошёл / не в сети), автостатус по подключению.
- Завершение диалога, назначение оператора.

## Технологии

- **Backend:** Node.js, Express, Socket.IO
- **Хранилище:** SQLite (better-sqlite3), файл в `data/chat.db`
- **Frontend:** ванильный HTML/CSS/JS, без сборки

## Запуск

```bash
npm install
npm run seed     # опционально: добавить примеры шаблонов
npm start
```

Затем откройте:
- Демо-сайт с виджетом: <http://localhost:3000/demo/>
- Панель оператора: <http://localhost:3000/operator/>

Проверка: напишите сообщение из виджета на демо-сайте, откройте панель
оператора в другой вкладке, войдите под любым именем и ответьте — сообщения
идут в реальном времени в обе стороны. Пока вы печатаете в виджете, оператор
видит ваш текст в жёлтой плашке ещё до отправки.

## Встраивание на свой сайт

```html
<script src="https://ВАШ-ХОСТ/widget/widget.js"
        data-title="Поддержка"
        data-subtitle="Отвечаем быстро"
        data-accent="#6d5efc"></script>
```

## Дорожная карта

Заложена архитектура для дальнейшего роста: поле `channel` в диалогах (под
омниканальность — Telegram/WhatsApp/VK/Email), типы отправителя `bot` (под
чат-ботов и ИИ-ассистента), триггеры/автоприглашения, аналитика (источники,
время ответа, оценки), реальный geo-IP, аутентификация операторов с паролем.
